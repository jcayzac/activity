# Order files top-down for skimming

Rule id: `visibility-layout/top-down-file-order`

**Rationale:** Readers skim. The file should surface the main entry point first
and use surrounding items as a progressively deeper table of contents.

**Origins:** `M-ITEM-TOC`, `M-TYPE-ASSOC`, `M-ASSOC-TRAIT`, `M-CALLER-CALLEE`,
`M-PUB-PRIV`, `M-AMBIGUITY` [EP].
