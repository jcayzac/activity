# Make examples copy-safe

Rule id: `api-documentation/copy-safe-examples`

**Rationale:** Users copy examples. Examples should teach correct error
propagation by default.

**Origins:** `C-QUESTION-MARK` [API]; Item 18, "Don't panic" [ER]; Item 27,
"Document public interfaces" [ER].
