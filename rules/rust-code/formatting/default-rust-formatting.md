# Use default Rust formatting

Rule id: `formatting/default-rust-formatting`

**Rationale:** Mechanical consistency is not the interesting part of review. The
formatter should remove style churn so reviews can focus on behavior and design.

**Origins:** `Formatting conventions`, `Indentation and line width`,
`Trailing commas`, `Blank lines`, `Comments`, `Doc comments`, `Attributes`
[RSG]; `DENV-FORMAT` [ANSSI].
