# Benchmark and track performance when performance matters

Rule id: `build-performance/benchmark-track-performance`

**Rationale:** Performance claims based on anecdotes are unreliable. Regular
benchmarking catches regressions and grounds optimization work in actual
behavior.

**Origins:** Item 30, "Write more than unit tests" [ER]; "Benchmarking" [RPB].
