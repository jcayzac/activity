# Make directory roots and preludes tables of contents

Rule id: `modules/directory-roots-preludes-toc`

**Rationale:** Readers should not have to guess whether the logic lives in the
module root or in one of its children. Module roots should orient the reader,
not hide logic.

**Origins:** `P-DIR-MOD`, `P-PRELUDE-MOD` [EP].
