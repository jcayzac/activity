# Record architecture-significant decisions

Rule id: `governance/architecture-decision-records`

**Rationale:** Architectural intent that lives only in memory or chat history is
not architecture. ADRs preserve context, rationale, and consequences for future
maintainers.

**Origins:** "Using architectural decision records to streamline technical
decision-making for a software development project" [ADR].
