# Break functions into visual paragraphs

Rule id: `function-structure/visual-function-paragraphs`

**Rationale:** Function bodies should read like short technical prose.
Paragraphs make the logic skimmable.

**Origins:** `F-GROUP`, `F-OUT` [EP].
