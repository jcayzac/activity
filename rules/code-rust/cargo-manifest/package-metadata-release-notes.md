# Fill in standard package metadata and keep release notes

Rule id: `cargo-manifest/package-metadata-release-notes`

**Rationale:** Package metadata and release notes are part of the public
contract. They help users evaluate, adopt, and upgrade the crate correctly.

**Origins:** `C-METADATA`, `C-RELNOTES` [API]; `Metadata conventions` [RSG].
