# Write more than unit tests

Rule id: `build-performance/more-than-unit-tests`

**Rationale:** Unit tests alone do not catch public API drift, documentation
rot, or many failures triggered by real-world or untrusted inputs.

**Origins:** Item 30, "Write more than unit tests" [ER].
