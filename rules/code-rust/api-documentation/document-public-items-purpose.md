# Document every public item and show why it exists

Rule id: `api-documentation/document-public-items-purpose`

**Rationale:** Good docs reduce guesswork and support review. Examples that show
intent are more valuable than examples that merely compile.

**Origins:** `C-CRATE-DOC`, `C-EXAMPLE` [API]; Item 27, "Document public
interfaces" [ER].
