# Link related items in rustdoc prose

Rule id: `api-documentation/link-related-items-rustdoc`

**Rationale:** Good rustdoc should be navigable. Links let reviewers and users
move directly between concepts without guessing paths.

**Origins:** `C-LINK` [API].
