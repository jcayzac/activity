# Follow standard Rust casing

Rule id: `naming/standard-rust-casing`

**Rationale:** Readers should not have to relearn naming rules from project to
project. Standard casing makes APIs legible and searchable.

**Origins:** `C-CASE` [API]; `Names` [RSG]; `Naming` [ANSSI].
