# Contributing to Rust Code Rules

This rule book merges external Rust coding guidance into one enforceable house rule set.

## Established precedence

When sources disagree, precedence is: [EP], [API], [RSG], [ANSSI], [RDP], [ER], [RPB], [MS], [DDIA]. Lower-precedence sources are used only to fill gaps left by higher-precedence ones.

Section identifiers such as `P-MOD`, `C-GETTER`, or `LANG-UNSAFE` are the original guides' own rule names when they exist.

## Sources

- [API] The Rust API Guidelines: https://github.com/rust-lang/api-guidelines/blob/master/src/SUMMARY.md
- [RSG] The official Rust Style Guide: https://github.com/rust-lang/rust/blob/main/src/doc/style-guide/src/SUMMARY.md
- [ANSSI] The ANSSI Rust Guide: https://github.com/ANSSI-FR/rust-guide/blob/master/src/en/SUMMARY.md
