# Keep boundary contracts purposeful and small

Rule id: `boundaries/purposeful-small-contracts`

**Rationale:** Narrow contracts reduce coupling and make the boundary tell the
truth about what the application actually needs from the other side.

**Origins:** "Hexagonal architecture" [HEX]; "Service Layer" [SL];
"Hexagonal architecture pattern" [AWS].
