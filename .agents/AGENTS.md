# Instructions for agents

## Important Files

- `README.md` is the main entry point for user-facing documentation. It can be ignored when looking for maintainer-facing documentation.
- `CONTRIBUTING.md` is where the maintainer-facing documentation starts. It links to `development/`, which is where the maintainer-facing documentation lives.
- `rules/` is where all the rule books live. See the `README.md` in that directory for instructions on how to use them.
