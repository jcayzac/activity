Protobuf decoding and binary container reading for macOS Biome stream files.

The `biome` module is generated at build time from `.proto` definitions for two Biome stream formats: App.InFocus (`InFocusRecord`) and WiFi connection sessions. `parse_infocus_record(slot: &[u8]) -> Option<InFocusEvent>` decodes a single SEGB slot into a focus-gained event; it performs a tolerant field-by-field scan to locate the end of valid proto content before passing bytes to prost, which is necessary because SEGB slots contain zero-padding and a 4-byte CRC after the proto payload. `scan_wifi_records(file_bytes: &[u8]) -> Vec<WifiConnectionEvent>` finds WiFi connection records by scanning for the `/wifi/connection` byte marker, since Biome WiFi files do not use SEGB framing.

The `segb` module implements a streaming reader for the SEGB binary container format used by all Biome App.InFocus files. A SEGB file has a variable-length header terminated by a delimiter sentinel, followed by a sequence of records each preceded by the four-byte delimiter `[0x0a, 0x00, 0x00, 0x00]`. `iter_records(path) -> Result<RecordIter>` reads the file once into memory and returns an iterator over raw record payloads.
