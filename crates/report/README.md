Report data types and builders for the `activity` tool. This crate contains no I/O and no rendering — it is pure domain logic that transforms a classified `Vec<Interval>` into a structured report ready for a renderer to consume.

`build_day_report(date, intervals, dominant_id, other_ids) -> DayReport` slices the interval list from the first to the last active interval (inclusive), drops zero-duration entries, and sums total active time. `build_month_report` iterates over all dates in a month, skipping days with no activity and days in the future, and produces a `MonthReport` whose rows each carry the day's first and last active timestamps, total active time, location identifiers sorted with the dominant location first, and a list of break/transit intervals that fall within the active span.
