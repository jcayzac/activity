Location identity inference for the `activity` tool. Given two sets of time-overlapping signals — Duet Expert Center location anchors (namespaced `duet:<uuid>`) and WiFi subnet periods derived from IP address changes (namespaced `subnet:<cidr>`) — this crate determines which physical location a given time interval should be attributed to.

The algorithm builds a weighted co-occurrence graph: edges connect signals that overlap in time, with weights proportional to overlap duration, decayed exponentially by age (half-life of fourteen days). Kruskal union-find clustering then merges signal nodes whose edge weight exceeds a threshold (one hour equivalent), producing location clusters each represented by a single canonical ID. `load_rto_data` returns an `RtoData` value containing the resolved `RtoBlock` list, the dominant office location (the cluster most associated with the configured office SSID), and any other identified locations. Home anchors (`ANCHOR_LOCATION_TYPE_HOME`) are excluded from RTO classification. Results are persisted in a SQLite cache database.
