Core timeline-building algorithm and date utilities for the `activity` tool. Ported from the earlier TypeScript implementation.

The main entry point is `build_timeline(inputs: TimelineInputs) -> Vec<Interval>`, which takes event streams from all sources and produces a classified sequence of `Interval` values. Each `Interval` carries `first_ms`, `last_ms`, and a label of `Active`, `Break`, or `Transit`. Gaps between active periods shorter than five minutes are merged; periods shorter than ten minutes are dropped as noise; a session opened without a hard-close event is soft-closed after thirty minutes of keyboard inactivity. `annotate_intervals_with_location` attaches a location identifier to each interval after RTO data has been resolved. `merge_focus_streams` combines focus event streams from multiple sources (Biome, knowledgeC, Powerlog) with deduplication and gap-filling before timeline construction.

The `date_utils` module provides pure date/time helpers: `format_local_date`, `next_day`, `six_am_of`, `effective_day` (times before 06:00 local belong to the previous calendar day), `days_in_month`, and `build_month_dates`. All functions operate in the local timezone to match the original TypeScript behavior.
