The binary crate for the `activity` tool. Accepts one positional argument in any of the four formats `YYYY-MM-DD`, `YYYYMMDD`, `YYYY-MM`, or `YYYYMM`, and an optional `--color=never|always|auto` flag (default: auto, which respects the `NO_COLOR` environment variable and checks whether stdout is a terminal).

`main.rs` parses the argument and dispatches to `app::run_day` or `app::run_month`. `app.rs` orchestrates the full pipeline: it loads config, opens all source databases, imports new events from system files since the last cached timestamp, builds the timeline, resolves location/RTO data, builds a `DayReport` or `MonthReport`, and passes the result to the terminal renderer. `terminal.rs` formats the report as a Gruvbox-themed colored table using 24-bit ANSI escape codes. Active durations are green; break and transit durations are orange; chrome (headers, dividers) is muted brown. The RTO column shows a check mark for the dominant office location and superscripts or an asterisk for other identified offices.
